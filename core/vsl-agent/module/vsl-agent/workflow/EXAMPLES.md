# Structural study cards

The 34 cards are short structural observations, not transcripts, endorsements or evidence of results. Use only the structure that fits the user’s own offer. Never borrow product claims, numbers, studies, testimonials, characters, distinctive creative or urgency.

## Original practice examples

These scenarios are fictional drafting exercises, never evidence for a real customer.

| Offer | Framework | Opening direction | Demonstration | Next action |
| --- | --- | --- | --- | --- |
| Bookkeeping reset call | Consultation | Show the pile of unanswered receipts | Walk through the real intake board | Book a fit call |
| Coaching course | Question-led education | Answer one question prospects already ask | Show a lesson and the course schedule | View course details |
| Local spa first visit | Founder or demonstration | Show what arrival actually looks like | Walk through facilities and the booking process | Choose an appointment |
| Sauna | Product demonstration | Show dimensions in a real room | Demonstrate controls and installation requirements | Request a quote |
| Water filter | Mechanism education | Explain one published specification | Show cartridge replacement; lab claims require the business’s own report | View compatible models |
| Workflow software | Workflow demo | Show a missed follow-up in an example project | Complete the same task in the product | Start the documented trial |

## Rewrite discipline

Use the user’s voice and approved facts. For each beat name its job, source, visual and transition. Present price, billing, delivery, eligibility and real refund terms before the final CTA. Include deadlines or guarantees only when documented. Prefer a plain example to a fabricated success story. Missing proof can be replaced by a truthful product demonstration, never by invented customers.
