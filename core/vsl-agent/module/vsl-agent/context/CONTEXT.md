# Working Context

Provide an offer, audience, problem, mechanism, objections, material terms, and only verifiable proof. Keep private customer records, source documents, and unpublished creative outside this module.

Every field you leave blank shows up as a blocked beat naming what is missing. That is deliberate: a gap in the brief is a gap in the video, and this module will not paper over it with a plausible sentence. When evidence is missing, the proof beat is marked blocked rather than filled.
